# Киноатлас

Интерактивная карта событий мирового кино: **50 сцен, 34 фильма, 20 стран**.

Сайт: [drozdovaekaterina.github.io/KinoAtlas](https://drozdovaekaterina.github.io/KinoAtlas/)

## Возможности

- Карта мира с группировкой соседних точек и подробной подложкой при приближении.
- Карточки с настоящими кадрами, названиями, режиссёрами, датами первого выпуска и описаниями сцен.
- Поиск по русскому и оригинальному названию, режиссёру, городу и стране.
- Фильтры по части света, стране действия, десятилетию и жанру.
- Коллекция фильмов, просмотр всех мест одного фильма, случайная сцена.
- Скрытие сюжетных описаний и прямые ссылки на сцены.
- Адаптация для телефонов и клавиатурная навигация. Клавиша `/` открывает поиск.

## Запуск локально

Сборка и установка пакетов не нужны. Из папки проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/`. Открытие `index.html` напрямую через `file://` не подходит: браузер должен получить `data.json` и географию через HTTP.

## Как пополнить коллекцию

Всё содержимое хранится в **data.json**. Чтобы добавить фильм:

1. Добавьте объект в массив `films`: уникальный `id`, `title`, `original`, `director`, `genre`, `release`, `source`, `image`, `imageSource`.
2. Положите кадр в `assets/`. Укажите относительный путь в `image`, страницу-источник — в `imageSource`. Добавьте атрибуцию в `SOURCES.md`.
3. Добавьте сцену в `scenes`: уникальный `id`, `film` (ID фильма), `title`, `place`, `country`, числовые `lat` и `lng`, `description`, `precision`, `note`, `locationSource`.
4. `precision: "exact"` — узнаваемое реальное место. `"approx"` — город или регион; обязательно поясните условность в `note`. Не выдавайте съёмочный адрес за адрес событий.
5. `release` поддерживает `ГГГГ-ММ-ДД`, `ГГГГ-ММ` и `ГГГГ`. Используйте ранний подтверждённый показ, включая фестиваль; неизвестный день не придумывайте. Дополнительная ссылка на дату — `releaseSource`.
6. Запустите проверки и сохраните изменения в ветке `main`. GitHub Pages обновит сайт автоматически.

Счётчики, список десятилетий, стран, жанров и коллекция обновляются по данным автоматически. При добавлении страны из другого региона проверьте функцию `regionFor` в `app.js`.

## Проверки

```sh
node --check app.js
node --test tests/catalog.test.mjs
```

Проверки находят потерянные кадры и источники, неверные даты и координаты, повторяющиеся ID, ссылки сцен на несуществующий фильм, а также непригодную географию мира. Браузерные сценарии и адаптацию дополнительно проверяют в реальном браузере.

## Карта, даты и изображения

Обзорная география **Natural Earth** хранится локально. При масштабе 5 и выше подгружаются тайлы **OpenStreetMap** с видимой атрибуцией. Ключей API и серверной базы нет; при недоступности тайлов остаются общая география и точки. Тайлы не предзагружаются для офлайн-работы.

Кадры иллюстрируют фильмы и **не обязательно относятся к описанным эпизодам**. Вымышленные города и съёмочные подмены оговорены в карточках. Даты отражают первые показы, найденные в указанных источниках, а не российский прокат. Для двух записей точный день не указан из-за недостаточной уверенности источников.

Источники: [SOURCES.md](SOURCES.md). Лицензии библиотек: [vendor](vendor/).

## GitHub Pages

В настройках репозитория: **Settings → Pages → Deploy from a branch → main → / (root)**. Файл `.nojekyll` отключает ненужную обработку Jekyll. Файлы проекта не содержат секретов или API-ключей.
